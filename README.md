# Swiggy Order Analytics Dashboard

## Project Overview

This project focuses on analyzing Swiggy-style food delivery data using **Microsoft Power BI**.

The dataset consists of three related tables: **Orders, Customers, and Restaurants**. The dashboard was created to analyze revenue, order volume, customer behavior, restaurant performance, delivery time, payment methods, discounts, and cancellations.

This project was part of my learning and practice in **Power BI, data modeling, data cleaning, and dashboard development**.

## What I Worked On

* Worked with multiple related datasets.
* Cleaned and prepared the data using Power Query.
* Removed duplicate records and invalid transactions.
* Standardized text fields and data types.
* Handled missing values in relevant columns.
* Combined date and time information for time-based analysis.
* Created a structured data model connecting Orders, Customers, and Restaurants.
* Created Pivot-style analytical views and Power BI visualizations.
* Built an interactive dashboard using KPIs, charts, and filters.

## Dashboard Analysis

The dashboard covers:

* Total Revenue
* Total Orders
* Average Order Value
* Cancellation Rate
* Monthly Revenue Trend
* Orders by Payment Method
* Top Restaurants by Revenue
* Order Status by Cuisine
* Revenue and Orders by City
* Restaurant Rating vs Average Order Value

## Filters

The dashboard allows analysis using filters such as:

* City
* Cuisine
* Date Range
* Payment Method
* Order Status

## Business Areas Analyzed

The project explores several practical business questions:

* Which restaurants generate the most revenue?
* How does revenue change over time?
* Which cities generate more orders and revenue?
* Which payment methods are used most frequently?
* Which cuisines have higher order volumes?
* How do restaurant ratings relate to order value?
* Where are cancellation patterns more prominent?
